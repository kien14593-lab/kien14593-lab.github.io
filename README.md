# Trang chuyển link

Kho này chỉ dùng để **chuyển link cũ của game sang link mới**:

- Link cũ: https://kien14593-lab.github.io/vuong-quoc-toan-hoc/
- Link mới: https://kien14593-lab.github.io/vuong-quoc-hoc-vui/

Ai mở link cũ (kể cả link đã gửi cho học sinh, phụ huynh) sẽ tự được đưa sang link mới. Dữ liệu chơi của các bé không bị mất.

- `vuong-quoc-toan-hoc/index.html`: mở đúng link cũ thì chuyển ngay sang link mới.
- `404.html`: các đường dẫn cũ khác cũng được chuyển sang link mới.

⚠️ Xin đừng xoá hoặc đổi tên kho này, và đừng tạo kho nào tên `vuong-quoc-toan-hoc` (sẽ làm hỏng việc chuyển link).
